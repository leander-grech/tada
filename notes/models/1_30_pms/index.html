    1_30_pms¶

    Research note

    Part of the development diary of the single-agent work, kept for reference. Model names such as 1_38 are internal run ids (the published TMB and PMS policies are 1_76 and 1_77). File paths and commands refer to the private development repository, and numbers were measured with the evaluation setup of the time. The published design is under How it works; the final results are under Results.

    complete

    What changed: BGY point-merge scenario. Not described in the docs or commit messages beyond its run name. The best point-merge agent so far.

    Scorecard¶

    Simulator

    Scored on flight_simulator 0.1.52, the simulator these runs trained on. The windowed track uses 0.2.8x, on which the same seeds generate different scenarios, so the two tracks' numbers do not compare.

    10-aircraft BGY point merge, the fixed 100-seed pool, deterministic. Success = tier 5: every aircraft landed within ±60 s of its AMAN target, no loss of separation. Clean-subset success = success among episodes without a loss of separation.

    Reproduce¶

    python analysis/score_checkpoints.py --seeds 100 --models experiments/atc_run_1_30_pms/final_model.zip
python analysis/attempts_to_solve.py --model experiments/atc_run_1_30_pms/final_model.zip --seeds 100 --max-attempts 20

    Training command: the run's run_meta.json and snapshot/ record what it ran. Runs up to 1_25 are not replayable on today's code (their observation encoding predates 1_26).
