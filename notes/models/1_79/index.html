    1_79¶

    Research note

    Part of the development diary of the single-agent work, kept for reference. Model names such as 1_38 are internal run ids (the published TMB and PMS policies are 1_76 and 1_77). File paths and commands refer to the private development repository, and numbers were measured with the evaluation setup of the time. The published design is under How it works; the final results are under Results.

    complete release MDP point merge

    What changed: Fine-tune stage 3, feasible streams only: 1_75 continued for 5M steps at LR 1e-5 to 1e-6, entropy 0.001 (2% warm-up, 100k critic warm-up) on the feasible point-merge pool, the control for the lower LR and entropy alone.

    Release MDP

    This model trained in the release MDP, unlike the champion and every model before 1_49: after each step the front of the landing queue is released once a flight is locked (predicted within 30 s of its target and in no predicted conflict). A released flight leaves the window and can no longer be cleared. It is scored in the same environment, on the same seeds and with the same metrics, so its numbers measure landings in the same scenarios, but under that extra constraint on the agent.

    Point merge

    Trained and scored on the BGY point merge (VALIDATION_USE_CASE_2), not the MXP trombone: every score on this card is a point-merge score, on the same 100 validation seeds. It is compared only with point-merge scores: its parent's and the MXP champion's zero-shot scores (Point merge), or a point-merge parent's own. It uses the canonical point-merge clearance set (v2pms); the MXP champion's zero-shot score, and any point-merge run trained before v2pms, used the old point-merge action model, so those comparisons also cross that change.

    Reproduce¶

    TADA_SEQUENCE_OBS=1 TADA_MAX_PICKS=2 TADA_ACTION_SET=v2pms TADA_MASK_FRAME_FIX=1 python -u main_jax.py --env windowed --use-case 2 --reward-mode outcome_pbrs --hard-bracket --release-locked --pay-at-release --flat-deviation --train-seed-pool analysis/2026-10-07_curriculum/pool/pms_feasible.txt --init-weights experiments/atc_run_1_75_ft_pms_1_67/final_model.zip --n-envs 32 --critic-warmup-steps 100000 --lr-max 1e-05 --final-lr 1e-06 --ent-coef 0.001 --warmup-frac 0.02 --vf-coef 0.25 --target-kl 0.05 --total-timesteps 5000000 --seed 79
