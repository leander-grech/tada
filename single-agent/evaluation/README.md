# Selected evaluation tools

The selected policies are TMB (`v2`, procedure airport mask) and PMS (`v2pms`). Full-episode rollout search uses K=8 candidates and replans every M=10 decisions. Attempt 0 and sampled attempts must be reported with their exact seeding and budget.

- `run_search.py`: search evaluation with per-episode, per-aircraft and optional pick records; supply the selected model with `--model` and its procedure with `--procedure`.
- `export_csv.py`: convert evaluation outputs into the per-episode/per-aircraft sheet format; supply `--raw` and `--out`.
- `seeds.txt`: supplied evaluation inputs.

The selected models are included in [artifacts/single_agent](../README.md#selected-models); evaluation outputs are generated by these tools. Explicitly configure the generator, paths and native runtime. For comparison with selected MA data, match TMB extra-TTL settings and scenario identities and disclose search-budget differences.

Validate the full expected procedure/seed/attempt/aircraft key set before export. Report unknown timing explicitly and keep warning-pair counts separate from realized loss-of-separation outcomes.

See the [single-agent guide](../README.md) for complete commands and environment settings for both selected models.
